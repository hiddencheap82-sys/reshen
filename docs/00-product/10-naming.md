## معیارها

هر اسمی که انتخاب شود، باید از این پنج سد رد شود:

| معیار | چرا |
|---|---|
| **نویسه‌گردانی یکتا** | مشتری باید بتواند تلفنی بگوید و طرف درست تایپ کند |
| **۴ تا ۸ حرف لاتین** | دامنهٔ بلند روی کارت ویزیت و بیوی اینستاگرام جا نمی‌شود |
| **بدون ق، ژ، ذ/ز/ض** | «قیچی» می‌شود gheychi یا gheichi یا qeychi — هر سه غلط‌اند |
| **معنی برای آرایشگر** | خریدار ما صاحب سالن است، نه طراح |
| **دامنهٔ آزاد** | .ir مهم‌تر از .com است؛ بازار داخلی است |

معیار سوم بی‌رحم است و نیمی از نام‌های خوب فارسی را حذف می‌کند:
**قیچی، آینه، وقت‌شناس، سرِوقت** همه به‌خاطر «ق» می‌افتند.

## گزینه‌ها

### ۱. رشن — بماند *(پیشنهاد اول)*

**رَشْن** در سنت ایرانی ایزدِ **داد و راستی** است؛ همان که ترازو به
دست دارد و حق را می‌سنجد.

شعار محصول: **«زمانِ راست می‌گوید»**.

این تصادف نیست — اسم *همان* وعدهٔ محصول است. کمتر نامی این‌قدر دقیق
روی کارکردش می‌نشیند.

| | |
|---|---|
| نویسه‌گردانی | `reshen` — یک شکل، بدون ابهام |
| طول | ۶ حرف |
| هزینهٔ تغییر | صفر — الان در ۱۱۲ جای کد، لوگو (ر)، مانیفست PWA و ۳۶ جای اسناد هست |
| ضعف | آرایشگری که اولین بار می‌شنود، نمی‌فهمد محصول چه می‌کند |
| ضعف دوم | در گفتار ممکن است «روشن» شنیده شود |

ضعف اول را تگ‌لاین جبران می‌کند: **«رشن — نوبت‌دهی آرایشگاه»**. تقریباً
همهٔ برندهای موفق همین‌طورند؛ «اسنپ» هم به‌خودی‌خود یعنی هیچ.

### ۲. نوبان — ساخته‌شده، کوتاه، شفاف

**نو‌بان** = نگهبانِ نوبت. پسوند «ـبان» (باغبان، دربان، مرزبان) برای
هر فارسی‌زبانی بدون توضیح خواناست.

| | |
|---|---|
| نویسه‌گردانی | `noban` — بدون ابهام |
| طول | ۵ حرف |
| قوت | ساخته‌شده است، پس شانس آزاد بودن دامنه‌اش بالاست |
| قوت دوم | دقیقاً کاری را می‌گوید که محصول می‌کند: نوبتت را نگه می‌دارد |
| ضعف | معنایش تازه است؛ کسی از قبل نمی‌شناسدش |

**اگر بخواهید اسم عوض شود، این پیشنهاد اول من است.**

### ۳. نوبتم — جملهٔ خودِ مشتری

مشتری در ذهنش می‌پرسد «نوبتم کِی می‌شه؟». اسم، همان جمله است.

| | |
|---|---|
| نویسه‌گردانی | `nobatam` |
| طول | ۷ حرف |
| قوت | گرم، شخصی، بی‌نیاز از توضیح |
| ضعف | بوی B2C می‌دهد، در حالی که خریدار صاحب سالن است |
| ضعف دوم | `nobat.*` پرتقاضاترین ریشه در این دسته است؛ احتمال گرفته بودن بالا |

## پیشنهاد

**رشن را نگه دارید، مگر اینکه دامنه‌اش گرفته باشد.**

دلیل: معنایش دقیقاً وعدهٔ محصول است، هزینهٔ تغییرش صفر است، و ضعفش
(ناآشنایی) با یک تگ‌لاین حل می‌شود — نه با عوض کردن اسم.

اگر `reshen.ir` گرفته بود، **نوبان** جایگزین من است.

## بررسی دامنه

```bash
tools/check-domain.sh reshen noban nobatam pirayesh
```

**برای `.ir` تنها مرجع قطعی [nic.ir](https://www.nic.ir) است** —
اسکریپت فقط رکورد DNS را می‌بیند و دامنهٔ ثبت‌شدهٔ بی‌استفاده را
«شاید آزاد» نشان می‌دهد.

## اگر تصمیم به تغییر گرفتید

اسم در سه لایه است و هر سه باید با هم عوض شوند:

| کجا | چند مورد | چطور |
|---|---|---|
| متن فارسی در ویوها | ۱۴ | جست‌وجوی «رشن» |
| کد و پیکربندی | ۱۱۲ | جست‌وجوی `reshen` — شامل کلید نشست، نام فایل قفل، مانیفست |
| اسناد | ۳۶ | جست‌وجوی «رشن» |

لوگو حرف **ر** است (`layouts/panel.php` و `auth.php`) و باید دستی
عوض شود.
