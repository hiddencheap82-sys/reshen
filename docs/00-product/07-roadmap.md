# ۰۷ — نقشهٔ راه

استراتژی در یک خط: **اول عرضه را جمع کن، بعد تقاضا را.**

مارکت‌پلیس‌ها (موکات، موآرا) از سمت تقاضا شروع کردند و باید برای هر کاربر هزینهٔ جذب بدهند. ما از
سمت عرضه شروع می‌کنیم — سالن‌ها را تک‌تک می‌فروشیم — و مشتری‌ها **رایگان** و از طریق خودِ سالن‌ها
به ما می‌رسند. وقتی چند صد هزار شماره داشتیم، چرخش به مارکت‌پلیس تقریباً بی‌هزینه است.

```
فاز ۰            فاز ۱             فاز ۲              فاز ۳              فاز ۴
کشف         →   MVP + پایلوت  →   ۱۰ سالن پولی  →   ۱۰۰ سالن      →   مارکت‌پلیس
۲ هفته          ۸ هفته            ۱۰ هفته            ۶ ماه              سال ۲
                                   ▲                                      ▲
                          دروازه: MAE < ۱۲ دقیقه        دروازه: ۵۰۰ سالن + ۲۵۰ هزار شماره
```

---

## فاز ۰ — کشف (۲ هفته)

**هدف:** فرضیه‌های سند [۰۵](05-prd.md) بخش ۷ را قبل از نوشتن کد، رد یا تأیید کن.

| کار | خروجی |
|---|---|
| **یک روز کامل در ۳ سالن بایست** (یکی‌اش حتماً پنجشنبه) | دفترچهٔ مشاهده: واقعاً چند نفر از دم در برمی‌گردند؟ |
| ۱۵ مصاحبه با صاحب سالن و آرایشگر | تأیید ف۱، ف۳، ف۵ |
| ۲۰ مصاحبهٔ کوتاه با مشتری (جلوی سالن) | تأیید ف۲، ف۴ |
| حساب آزمایشی در ۷ رقیب ایرانی + پر کردن جدول [۰۲ §۵](02-competitors.md) | نقشهٔ واقعی شکاف‌ها |
| خواندن کامل نظرات ۱ و ۲ ستارهٔ اپ‌های رقیب در بازار | فهرست خرید |
| زنگ زدن به ۵ سالنی که رقیب را رها کرده‌اند | علت ریزش رقیب |
| آزمون قیمت: عدد را به ۱۵ نفر بگو و واکنش را ثبت کن | تأیید ف۳ |

**دروازهٔ خروج:** دست‌کم ۱۰ نفر از ۱۵ نفر، دو جملهٔ اول از [چهار جملهٔ سند ۰۳](03-personas-jtbd.md#چهار-جملهای-که-باید-در-فاز-۰-بشنویم) را
گفته باشند. اگر نه — **بچرخ**، کد نزن.

---

## فاز ۱ — MVP و یک سالن پایلوت (۸ هفته)

**هدف:** یک سالن سه‌صندلی، یک پنجشنبهٔ کامل، فقط با رشن.

**دامنه:** ۳۳ فیچرِ `M` فاز ۱ در [سند ۰۵ §۴](05-prd.md#۴-دامنهٔ-mvp--دقیقاً-چه-چیزی-در-فاز-۱-ساخته-میشود). نه یکی بیشتر.

**سالن پایلوت چطور انتخاب می‌شود:**
- ۳ تا ۴ صندلی (نه کمتر — صف معنا پیدا نمی‌کند؛ نه بیشتر — پیچیدگی زود می‌آید)
- صاحبش با موبایل راحت باشد
- **نزدیک محل کار تو** — هفته‌ای دو بار باید آنجا باشی
- رایگان، در ازای اجازهٔ حضور و مشاهده

**هفته به هفته:** [۲۰-تحویل / ۰۳ — برنامهٔ اسپرینت](../20-delivery/03-sprint-plan.md)

**دروازهٔ خروج (هر سه باید برقرار باشد):**
1. MAE تخمین **زیر ۱۲ دقیقه** در یک هفتهٔ کامل
2. نرخ ثبت «پایان خدمت» **بالای ۷۰٪**
3. صاحب سالن بگوید: **«دفترچه رو دیگه باز نمی‌کنم.»**

اگر ۳ محقق نشد، محصول مشکل دارد نه بازار. برنگرد به ساختن فیچر جدید.

## فاز ۲ — ۱۰ سالن پولی (۱۰ هفته)

**هدف:** اثبات اینکه غریبه‌ها هم پول می‌دهند.

| افزوده می‌شود | چرا حالا |
|---|---|
| A17 لیست انتظار خودکار | ارزان، پربازده، غیبت را به درآمد تبدیل می‌کند |
| C04 تأیید نوبت با لینک + C05/C06/C07 غیبت و بیعانه | بزرگ‌ترین درد پس از صف |
| B06 امتیاز اعتبار مشتری · B10 لیست بازگردانی · B12 نظرسنجی | جمع‌آوری دارایی فاز ۴ از همین حالا |
| D06–D09 **تسویهٔ صندلی** | ستون ۳ — دلیل پول دادن صاحب سالن |
| D11 داشبورد صاحب سالن · D12 **گزارش نجات‌یافته‌ها** | بدون این، تمدید نمی‌کنند |
| E01 کارت امتیاز · E08 پیامک «دلمون تنگ شده» | نگهداشت مشتری نهایی |
| G02 اشتراک و صورتحساب · G04 داشبورد شاخص‌ها · G05 دورهٔ آزمایشی | زیرساخت فروش |

**فروش:** حضوری، توسط بنیان‌گذار، در یک محدودهٔ جغرافیایی محدود. **عمداً همه در یک یا دو محله** —
تا اثر شبکهٔ محلی (سند [۰۴ §۳ج](04-core-feature.md)) را زودتر ببینیم و پشتیبانی حضوری ممکن باشد.

**دروازهٔ خروج:**
- ۱۰ سالن پرداخت‌کننده، **۸ تا تمدید ماه دوم**
- MAE **زیر ۷ دقیقه**
- نرخ غیبت سالن‌ها **زیر ۸٪**
- دست‌کم ۲ سالن از طریق **معرفی** آمده باشد ← این مهم‌ترین سیگنال است

## فاز ۳ — ۱۰۰ سالن و ماشین فروش (۶ ماه)

**هدف:** فروش دیگر به بنیان‌گذار وابسته نباشد.

| افزوده می‌شود | |
|---|---|
| E03 **اشتراک ماهانهٔ سالن** | بزرگ‌ترین اهرم درآمدی برای سالن |
| E02 باشگاه مشتریان · E05 تخفیف ساعت خلوت | |
| F12 چند شعبه | ورود به زنجیره‌های کوچک |
| A22 جابه‌جایی هوشمند · A21 تخصیص خودکار صندلی | عمق دادن به فیچر اصلی |
| A23 رزرو از دایرکت اینستاگرام | کانال واقعی بازار ایران |
| F13 انتشار در کافه‌بازار / مایکت | |
| D14 انبار · D15 مؤدیان | برای سالن‌های بزرگ‌تر |
| **G07 جستجوی سراسری سالن‌ها** | **اولین آجر مارکت‌پلیس** |

**تغییر کانال فروش:** از فروش حضوری به: معرفی مشتری (E07)، محتوای اینستاگرام، و **فروش تلفنیِ
یک نفر فروشنده**. CAC باید از ۲٫۵ م به زیر ۱ م برسد.

**دروازهٔ خروج:** ۱۰۰ سالن فعال · ریزش ماهانه زیر ۴٪ · CAC زیر ۱٫۲ م · سودده در سطح عملیاتی.

## فاز ۴ — چرخش به مارکت‌پلیس (سال ۲)

**فقط وقتی این دروازه باز شود:**
- **۵۰۰+ سالن فعال**
- **۲۵۰ هزار+ شمارهٔ موبایل** که دست‌کم یک بار لینک رشن را باز کرده‌اند
- در دست‌کم **یک شهر**، پوشش بالای ۱۵٪ سالن‌های مردانه

زودتر از این، مارکت‌پلیسِ خالی می‌شود و به برند آسیب می‌زند.

**چه چیزی عوض می‌شود — و چه چیزی نه:**

| عوض می‌شود | **عوض نمی‌شود** |
|---|---|
| صفحهٔ اصلی رشن به جستجوی سالن تبدیل می‌شود | **صفحهٔ اختصاصی هر سالن سر جایش می‌ماند** — همان آدرس، همان برند سالن |
| اپ مشتری در بازار منتشر می‌شود | سالن همچنان صاحب دادهٔ مشتریانش است |
| نظرات و امتیازها (جمع‌شده از فاز ۲) نمایش داده می‌شوند | اشتراک همچنان پایهٔ درآمد است |
| جستجو بر اساس محله، خدمت، قیمت، و **زمان انتظار زنده** | |

**«زمان انتظار زنده» در جستجو، همان تمایزی است که هیچ مارکت‌پلیسی نمی‌تواند کپی کند** — چون
دادهٔ لحظه‌ایِ صف را فقط ما داریم. «۳ آرایشگاه در ۸۰۰ متری تو، کوتاه‌ترین انتظار: ۱۰ دقیقه.»

**سه ریسک این چرخش:**
1. سالن‌ها احساس خطر کنند → **قرارداد عدم‌واسطه‌گری** ([۰۶ §۹](06-pricing-business-model.md)) از روز اول اعلام و فنی اجرا شود
2. کیفیت نظرات پایین باشد → از فاز ۲ جمع‌آوری شروع می‌شود تا در روز اول انبار پر باشد
3. تمرکز از ابزار برداشته شود → تیم ابزار باید جدا بماند

## آنچه عمداً هرگز نمی‌سازیم

| | چرا |
|---|---|
| سالن زنانه | منطق خدمات، مدت‌ها و رفتار کاملاً متفاوت است. تمرکز، تنها دارایی یک تیم کوچک است |
| حسابداری رسمی و دفاتر قانونی | بازار اشباع (هلو و…) و ما در آن مزیتی نداریم — به‌جایش API اتصال می‌دهیم |
| سخت‌افزار (کیوسک، کارتخوان اختصاصی) | سرمایه‌بر، و در ایران زنجیرهٔ تأمین شکننده است |
| اپ دسکتاپ ویندوزی | نسل قبل. موبایل، تنها دستگاهی است که همیشه دست آرایشگر است |
