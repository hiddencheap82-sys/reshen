# ۰۵ — چک‌لیست انتشار

پیش از اینکه اولین مشتری واقعی وارد سالن پایلوت شود.

## زیرساخت
- [ ] VPS ایرانی، PHP ≥ ۸٫۲، MySQL 8، Redis
- [ ] `php artisan reshen:doctor` همه سبز (به‌ویژه `soap`)
- [ ] HTTPS + HSTS · تمدید خودکار گواهی
- [ ] **cron برای `schedule:run`** ← بدون این، موتور ETA و پیامک‌ها کار نمی‌کنند
- [ ] Worker صف با supervisor و راه‌اندازی خودکار
- [ ] پشتیبان‌گیری روزانه **خارج از همان سرور** — و **یک بازیابی آزمایشی انجام شده**
- [ ] پایش آپ‌تایم + هشدار پیامکی به خودمان

## پیامک
- [ ] همهٔ الگوها تأیید شده‌اند
- [ ] ارائه‌دهندهٔ پشتیبان تست شده و سوئیچ خودکار کار می‌کند
- [ ] کیف سالن پایلوت شارژ است
- [ ] هر متن پیامک روی گوشی واقعی خوانده شده — طول، شکست خط، لینک

## داده
- [ ] خدمات و قیمت‌های واقعی سالن وارد شده
- [ ] آرایشگرها با ساعت کاری واقعی
- [ ] مدت اسمی هر خدمت **از خود آرایشگر پرسیده شده**، نه حدس زده شده
- [ ] تعطیلات رسمی سال جاری وارد شده
- [ ] مشتریان قدیمی (اگر لیستی هست) وارد شده

## عملیات
- [ ] **آموزش حضوری آرایشگرها** — مخصوصاً دکمهٔ «تمام شد»
- [ ] QR روی آینه و درِ سالن، چاپ‌شده و نصب‌شده
- [ ] شمارهٔ تماس مستقیم ما به صاحب سالن داده شده
- [ ] **برنامهٔ حضور فیزیکی هفتهٔ اول** مشخص است
- [ ] برنامهٔ بازگشت به دفترچه اگر همه‌چیز خراب شد

## نظارت
- [ ] داشبورد MAE و نرخ ثبت پایان بالا آمده
- [ ] لاگ خطا به جایی که می‌بینیمش می‌رود
- [ ] هشدار برای: خطای ارسال پیامک، کیف خالی، خطای درگاه

## حقوقی
- [ ] قرارداد سالن، شامل **بند عدم‌واسطه‌گری**
- [ ] شرایط استفاده و حریم خصوصی روی سایت
- [ ] متن رضایت عکس مشتری
