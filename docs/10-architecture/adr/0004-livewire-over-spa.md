# ADR-0004 — Livewire به‌جای SPA جدا

**وضعیت:** جایگزین‌شده با [ADR-0009](0009-vanilla-php-over-laravel.md) · **تاریخ:** ۱۴۰۵/۰۶/۲۷

> این تصمیم دیگر برقرار نیست. لاراول و Livewire کنار گذاشته شدند،
> چون هاست اشتراکی مشتری نه SSH دارد نه Node. دلیل کامل در
> [ADR-0009](0009-vanilla-php-over-laravel.md).

## زمینه
پنل سالن رابط پرتعاملی دارد (صف زنده، تقویم). گزینه‌ها: SPA با Vue/React و API، یا Livewire 3.

## تصمیم
**Livewire 3 + Alpine.js** برای پنل. صفحهٔ عمومی مشتری با Blade + Alpine به‌شکل PWA.

## دلیل
تیم کوچک است. SPA یعنی دو کدبیس، دو زنجیرهٔ بیلد، دو جای اعتبارسنجی، و همگام‌سازی دائمی
قرارداد API. Livewire همان تجربه را با نصف کار می‌دهد.

API همچنان نوشته می‌شود ([۰۵](../05-api.md)) — برای صفحهٔ مشتری و آمادگی اپ‌های فاز ۳ — ولی
پنل از آن استفاده نمی‌کند.

## گزینهٔ رد شده
**Vue 3 + API:** تجربهٔ روان‌تر، ولی در این مقیاس تیم، هزینه‌اش از فایده‌اش بیشتر است.

## پیامدها
- ✅ سرعت توسعهٔ بالا
- ✅ یک زبان، یک کدبیس
- ⚠️ هر تعامل یک رفت‌وبرگشت شبکه است — برای دکمهٔ «تمام شد» باید با `wire:loading` و به‌روزرسانی
  خوش‌بینانه پوشانده شود
- ⚠️ اگر روزی اپ نیتیو خواستیم، API آماده است
