# ADR-0009 — PHP خام به‌جای لاراول

**وضعیت:** پذیرفته · **تاریخ:** ۱۴۰۵/۰۷/۰۱
**جایگزین می‌کند:** [ADR-0004](0004-livewire-over-spa.md)

## زمینه

معماری اولیه بر پایهٔ Laravel 12 + Livewire 3 + Redis طراحی شده بود
(ADR-0004 و بخش «استک» در [نمای کلی](../01-overview.md)). آن طراحی
درست بود — برای محیطی که فرض می‌کرد.

فرض غلط از آب درآمد. مشتری واقعی ما آرایشگاه مردانه است و هاستش
cPanel اشتراکی ایرانی:

- بدون SSH — پس `composer install` روی سرور اجرا نمی‌شود
- بدون Node — پس `npm run build` روی سرور اجرا نمی‌شود
- بدون Redis و بدون فرایند دائمی — پس صف کار و Reverb بی‌معنی‌اند
- گاهی بدون امکان تغییر document root — پس `public/` جای همیشگی‌اش نیست
- نسخهٔ PHP دستِ هاست است، نه ما (مورد واقعی: ۸.۱.۳۴)

آرایشگر SSH ندارد و نباید داشته باشد. نصب باید یعنی «ZIP را آپلود کن،
اکسترکت کن، یک صفحه را باز کن».

## تصمیم

**میکروفریم‌ورک خودمان در `app/Core/` — دوازده فایل، بدون وابستگی
زمان‌اجرا جز کتابخانهٔ QR.**

- مسیریاب، پوستهٔ PDO، نشست، ویو، احراز هویت، مهاجرت‌گر، کرون
- خودبارگذار PSR-4 داخلی، تا نبودِ `vendor/` هم برنامه را نکشد
- CSS در زمان ساخت با Tailwind ساخته می‌شود و **در بسته** می‌آید
- بدون صف کار: کارهای زمان‌بندی‌شده با کرون cPanel یا `public/cron.php`

Livewire هم با همین کنار رفت: پنل با PHP و مقدار کمی جاوااسکریپت
ساخته می‌شود، و صف زنده با همان پولینگ [ADR-0005](0005-polling-before-websockets.md)
به‌روز می‌ماند.

## دلیل

- نصب واقعاً «آپلود و اکسترکت» می‌شود — همان چیزی که محصول قولش را داده
- بستهٔ نهایی حدود ۶۰۰ کیلوبایت است، نه چند ده مگابایت
- هر چیزی که نیست، نمی‌تواند خراب شود؛ روی هاستی که لاگ هم سخت
  دیده می‌شود، این ارزش دارد
- سطح کد آن‌قدر کوچک است که یک نفر بتواند کل `Core/` را یک عصر بخواند

## پیامدها

- ✅ روی هر هاست اشتراکی PHP 8.1 به بالا اجرا می‌شود
- ✅ بدون SSH و بدون Composer نصب می‌شود
- ⚠️ ORM نداریم؛ هر مخزن SQL خودش را می‌نویسد. محدود کردن با
  `salon_id` دستی است و با `TenantRequired` و تست پشتیبانی می‌شود
- ⚠️ صف کار پس‌زمینه نداریم؛ پیامک درجا فرستاده می‌شود و یادآورها
  با کرون می‌روند
- ⚠️ رویداد و Listener نداریم؛ دامنه‌ها مستقیم هم را صدا می‌زنند
- ⚠️ هر چیزی که فریم‌ورک مجانی می‌داد — اعتبارسنجی، CSRF، مهاجرت —
  خودمان نوشته‌ایم و خودمان باید نگهش داریم
- ⚠️ نسخهٔ PHP هدف باید سنجیده شود، چون ماشین توسعه از هاست جلوتر
  است. `tools/check-php-compat.sh` همین کار را می‌کند
