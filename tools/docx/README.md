# سازندهٔ سند Word

این پوشه، نسخهٔ Word سند محصول را از روی محتوای `docs/` می‌سازد:
`docs/reshen.docx` — ۴۴ صفحه، فارسی و راست‌به‌چپ.

```bash
npm install docx
node make.js          # خروجی: reshen.docx
```

## هشدار دربارهٔ دو منبع حقیقت

**مرجع، فایل‌های Markdown در `docs/` هستند.** این اسکریپت‌ها محتوا را
برای ارائه به بیرون (سرمایه‌گذار، شریک، مشتری) بازنویسیِ فشرده کرده‌اند،
نه اینکه از Markdown بخوانند. یعنی اگر سند محصول را عوض کردی، این‌ها
خودکار به‌روز نمی‌شوند.

اگر قرار شد سند Word زنده بماند، یا محتوا را از Markdown پارس کن،
یا این پوشه را پاک کن و فقط Markdown را نگه دار. وضعیت فعلی برای یک
خروجی یک‌باره درست است، برای نگهداری بلندمدت نه.

## نکته‌های فنی راست‌به‌چپ

چیزهایی که اگر نباشند، متن فارسی در Word خراب می‌شود:

| ویژگی | چرا لازم است |
|---|---|
| `bidirectional: true` روی پاراگراف | جهت پایهٔ پاراگراف |
| `rightToLeft: true` روی هر ران | جهت متن |
| `w:cs` در `rFonts` | فونت متن فارسی (complex script) — بدون این، فونت پیش‌فرض می‌گیرد |
| `w:szCs` | اندازهٔ متن فارسی — بدون این، اندازه اعمال نمی‌شود |
| `visuallyRightToLeft: true` روی جدول | ترتیب ستون‌ها از راست |
| `titlePage: true` | جلد بدون سربرگ و شمارهٔ صفحه |
| ارقام فارسی دستی در فهرست‌های شماره‌دار | `LevelFormat.DECIMAL` ارقام لاتین می‌دهد |
| `ShadingType.CLEAR` (نه `SOLID`) | `SOLID` کادر را سیاه می‌کند |
