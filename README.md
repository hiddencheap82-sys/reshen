# رشن

**سامانهٔ نوبت‌دهی و مدیریت آرایشگاه مردانه.**

> رشن زمانِ راست می‌گوید.

---

## مسئله

در آرایشگاه مردانهٔ ایران «نوبت ساعت ۶» یعنی «حدودای ۶ بیا». مشتری ۶ می‌آید و ۶:۴۰ روی صندلی
می‌نشیند. آن‌قدر عادی شده که کسی شکایت هم نمی‌کند — فقط دیگر از قبل نوبت نمی‌گیرد.

هیچ نرم‌افزاری این را حل نکرده، چون همه سالن را به یک **تقویم اسلات ثابت** تقلیل می‌دهند. ولی
آرایشگاه مردانه هم‌زمان با نوبت و با مراجعهٔ حضوری کار می‌کند، و «هر اصلاح ۳۰ دقیقه است» یک
فرض غلط است که تا ساعت ۸ شب، ۵۰ دقیقه انحراف می‌سازد.

## راه‌حل

یک **صف زنده** که نوبت رزروشده و مراجعهٔ حضوری را در یک لیست واحد می‌چیند، و **زمان راست**
می‌دهد — زمانی که از رفتار واقعی همان آرایشگر و همان مشتری یاد گرفته شده، نه از عدد اسمی خدمت.

```
┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓
┃  صندلی رضا — پنجشنبه ۱۷:۲۰                  ┃
┣━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┫
┃  ▸ روی صندلی   علی رحیمی     ~۱۰ دقیقه مانده┃
┃  ۱  حسین ن.   [رزرو ۱۷:۳۰]   ~۱۷:۳۵–۱۷:۴۵  ┃
┃  ۲  امیر ک.   [حضوری]        ~۱۸:۰۰–۱۸:۱۵  ┃
┃  ۳  ناشناس    [حضوری]        ~۱۸:۳۵–۱۸:۵۰  ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛
```

و پیامکی که همه‌چیز را عوض می‌کند:

> امیر جان، ۲ نفر جلوتری، حدود ۲۵ دقیقهٔ دیگه نوبتته. راه بیفتی خوبه.

## سه ستون

| ستون | چه کسی را می‌گیرد |
|---|---|
| **صف زنده** | **مشتری** را جذب می‌کند — و موتور رشد فاز مارکت‌پلیس است |
| **دفترچهٔ آرایشگر** | **آرایشگر** را نگه می‌دارد (شمارهٔ تیغ، فرم مو، عکس آخرین مدل) |
| **تسویهٔ صندلی** | **صاحب سالن** بابتش پول می‌دهد (درصد و اجارهٔ صندلی، خودکار) |

## استراتژی

**اول عرضه، بعد تقاضا.** فاز ۱ تا ۳: فروش تک‌به‌تک به سالن‌ها، زیر برند رشن، با صفحهٔ اختصاصی
برای هر سالن. فاز ۴: چرخش به مارکت‌پلیس سراسری — که تقریباً رایگان است، چون تا آن موقع چند صد
هزار شمارهٔ موبایل از طریق پیامک‌های صف با ما آشنا شده‌اند.

## استک

Laravel 12 · MySQL 8 · Redis · Livewire 3 · PWA · PHP 8.2+

**تماماً داخل ایران.** بدون Firebase، بدون Google Maps، بدون Stripe، بدون Pusher. پیامک با
ملی‌پیامک (و کاوه‌نگار به‌عنوان پشتیبان)، پرداخت با زیبال، نقشه با نشان.

## شروع

```bash
make setup     # نصب، کلید، مهاجرت، دادهٔ نمونه
make up        # بالا آوردن محیط با داکر
make doctor    # ★ بررسی محیط — به‌ویژه افزونهٔ php-soap
make check     # lint + تحلیل ایستا + تست، پیش از هر پوش
```

> **`make doctor` را جدی بگیر.** بدون افزونهٔ `php-soap`، ملی‌پیامک اصلاً کار نمی‌کند — و این را
> فقط وقتی می‌فهمی که اولین پیامک نرود. برای نصب روی هاست اشتراکی مشتری،
> [`tools/host-check.php`](tools/host-check.php) هست.

## قواعدی که شکسته نمی‌شوند

1. منطق کسب‌وکار در `app/Domain/` است، نه در کنترلر یا Livewire
2. هر مدل مستأجری `BelongsToSalon` دارد — تست معماری اجبارش می‌کند
3. پول `BIGINT` و به **ریال**؛ تاریخ در دیتابیس **UTC** و شمسی فقط در نمایش
4. «تمام شد» و «تسویه» یک عمل‌اند و هرگز جدا نمی‌شوند
5. هیچ استقراری پنجشنبه ۱۶–۲۲ و جمعه ۱۰–۱۴ — شلوغ‌ترین ساعات هفته
