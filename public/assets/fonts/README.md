# فونت‌ها

## چه فونتی الان استفاده می‌شود

**وزیرمتن** (Vazirmatn) — وزن‌های Regular و Bold، با لایسنس **SIL OFL**.
یعنی استفادهٔ تجاری‌اش آزاد است و می‌توانید محصول را بدون نگرانی بفروشید.

## دربارهٔ ایران‌یکان

ایران‌یکان (IRANYekan) فونت **تجاری مؤسسهٔ فونت ایران** است. استفادهٔ
شخصی و غیرتجاری‌اش آزاد است، ولی **برای محصول تجاری باید لایسنس بخرید**.
رشن قرار است به آرایشگاه‌ها فروخته شود، یعنی مصداق استفادهٔ تجاری است.

به همین دلیل ایران‌یکان در این مخزن نیست — نه به این خاطر که کار
نمی‌کند، بلکه چون توزیعش بدون لایسنس، شما را در معرض ادعای حقوقی
می‌گذارد.

## اگر لایسنس ایران‌یکان را دارید

سه قدم:

۱. فایل‌های `woff2` را با این نام‌ها اینجا بگذارید:

```
public/assets/fonts/IRANYekanX-Regular.woff2
public/assets/fonts/IRANYekanX-Bold.woff2
```

۲. در `.env` بنویسید:

```ini
UI_FONT=iranyekan
```

۳. تمام. نیازی به ساخت دوبارهٔ CSS نیست — `@font-face` هر دو خانواده
از قبل تعریف شده و `--font-sans` بر اساس همین متغیر عوض می‌شود.

## جایگزین‌های رایگان و مجاز

اگر لایسنس ندارید ولی وزیرمتن را نمی‌پسندید:

| فونت | لایسنس | نکته |
|---|---|---|
| **وزیرمتن** | OFL | پیش‌فرض فعلی؛ رایج‌ترین جایگزین ایران‌یکان |
| **استعداد** (Estedad) | OFL | هندسی‌تر، به ایران‌یکان نزدیک‌تر. باید از ttf به woff2 تبدیل شود |
| **ساحل** (Sahel) | OFL | |

برای افزودن هرکدام، همان سه قدم بالا با نام فایل خودش.
