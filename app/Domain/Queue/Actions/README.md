# کنش‌های دامنهٔ صف

هر کلاس، یک واحد کار با یک متد عمومی (`handle` یا `__invoke`).

| کنش | نکته |
|---|---|
| `AddWalkIn` | باید زیر ۳۰۰ میلی‌ثانیه پاسخ دهد — پرکاربردترین عمل کل محصول |
| `StartService` | معمولاً خودکار، وقتی نفر قبلی تمام می‌شود |
| `CompleteService` | ★ **پایان خدمت و تسویه یک عمل‌اند.** جدا کردنشان یعنی ریسک R1 |
| `SkipCustomer` | مشتری نیامد — به انتهای صف |
| `MarkNoShow` | |
| `RecalculateQueue` | پس از هر رویداد، و هر ۹۰ ثانیه |
| `RecordActualDuration` | تغذیهٔ `duration_stats` — حافظهٔ موتور ETA |

**قاعدهٔ حیاتی:** `CompleteService` هرگز نباید به دو اندپوینت جدا تقسیم شود. آرایشگر برای گرفتن
پول مجبور است «تسویه» را بزند؛ به همین دلیل «تمام شد» را به آن چسبانده‌ایم. اگر جدا شوند،
آرایشگر فقط تسویه را می‌زند و موتور ETA کور می‌ماند.
